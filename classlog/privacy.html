개인정보처리방침

최종 업데이트: 2026년 9월 26일

수업로그는 학생·학급·수업·평가·활동 기록을 관리하는 Windows 데스크톱 앱이며, 기능 제공에 필요한 범위에서만 Google API를 사용합니다.

1. Google API 사용

수업로그는 Google Drive API를 사용하여 여러 PC 사이에서 애플리케이션 데이터를 동기화하고, 사용자가 요청한 경우 Google Drive에 파일을 생성하거나 내보낼 수 있습니다.

2. 요청하는 Google 권한

  • Google Drive의 앱 데이터 영역에 접근하기 위한 권한
  • 수업로그가 생성하거나 사용하도록 허용된 Google Drive 파일에 접근하기 위한 권한

수업로그는 기능 제공에 필요한 범위의 권한만 요청합니다.

3. 데이터 저장

수업로그 데이터는 기본적으로 사용자의 PC에 저장됩니다. Google Drive 동기화를 사용하는 경우, 동기화 데이터는 로그인한 사용자의 Google Drive 앱 데이터 영역에 저장됩니다.

수업로그 개발자가 운영하는 별도의 중앙 서버에는 사용자의 학생, 학급, 수업, 평가 및 활동 데이터를 저장하지 않습니다.

4. 데이터 이용 목적

Google 사용자 데이터는 수업로그의 데이터 동기화, 백업·복구 및 사용자가 요청한 파일 내보내기 기능을 제공하기 위해 사용됩니다. 광고, 사용자 프로파일링 또는 데이터 판매 목적으로 사용하지 않습니다.

5. 데이터 공유 및 판매

수업로그는 Google API를 통해 얻은 사용자 데이터를 판매하지 않으며 광고 목적으로 제3자와 공유하지 않습니다.

6. 접근 권한 해제 및 데이터 삭제

사용자는 수업로그에서 Google 연결을 해제하거나 Google 계정 설정에서 수업로그의 접근 권한을 철회할 수 있습니다. 로컬 데이터와 사용자가 생성한 백업 파일은 사용자의 기기에서 직접 관리할 수 있습니다.

7. 정책 변경

기능 또는 데이터 처리 방식이 변경되는 경우 이 페이지의 개인정보처리방침을 갱신합니다.
