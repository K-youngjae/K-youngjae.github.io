개인정보처리방침

수업로그는 기능 제공에 필요한 범위에서만 사용자 데이터와 Google API 권한을 사용합니다. 사용자의 수업 데이터는 개발자가 운영하는 별도 서버에 저장되지 않습니다.

1. Google API 사용

수업로그는 Google Drive API를 사용하여 여러 PC 사이에서 애플리케이션 데이터를 동기화하고, 사용자가 요청한 경우 Google Drive에 파일을 생성하거나 내보낼 수 있습니다.

2. 요청하는 Google 권한

  • Google Drive의 앱 데이터 영역에 접근하기 위한 권한
  • 수업로그가 생성하거나 사용하도록 허용된 Google Drive 파일에 접근하기 위한 권한

수업로그는 기능 제공에 필요한 최소 범위의 권한만 요청합니다.

3. Google 사용자 데이터의 이용 목적

Google 사용자 데이터는 수업로그의 동기화 및 파일 내보내기 기능을 제공하기 위해서만 사용됩니다. 광고, 사용자 프로파일링 또는 별도의 상업적 목적으로 사용하지 않습니다.

4. 데이터 저장

동기화 데이터는 사용자가 로그인한 Google 계정의 Google Drive에 저장됩니다. 수업로그 개발자가 운영하는 별도의 서버에는 사용자의 학생, 학급, 수업, 평가 및 활동 데이터를 저장하지 않습니다.

5. 데이터 공유 및 판매

수업로그는 Google API를 통해 얻은 사용자 데이터를 판매하지 않으며, 광고 목적으로 제3자와 공유하지 않습니다.

6. 접근 권한 해제

사용자는 수업로그에서 Google 연결을 해제하거나 Google 계정의 보안 설정에서 언제든지 수업로그의 접근 권한을 철회할 수 있습니다.

7. Google API 데이터 정책

수업로그의 Google API를 통한 사용자 데이터 사용은 Google API Services User Data Policy와 해당 정책의 Limited Use 요구사항을 준수하는 범위에서 이루어집니다.

8. 정책 변경

기능 또는 데이터 처리 방식이 변경되는 경우 이 개인정보처리방침을 갱신합니다.
