개인정보처리방침

수업로그는 사용자의 개인정보와 수업 데이터를 최소한으로 취급하며, 기능 제공에 필요한 범위에서만 Google API를 사용합니다.

1. Google API 사용

수업로그는 Google Drive API를 사용하여 여러 PC 사이에서 애플리케이션 데이터를 동기화하고, 사용자가 요청한 경우 Google Drive에 파일을 생성하거나 내보낼 수 있습니다.

2. 요청하는 Google 권한

  • Google Drive의 앱 데이터 영역에 접근하기 위한 권한
  • 수업로그가 생성하거나 사용하도록 허용된 Google Drive 파일에 접근하기 위한 권한

수업로그는 기능 제공에 필요한 최소 범위의 권한만 요청합니다.

3. 데이터 저장 위치

동기화 데이터는 사용자가 로그인한 Google 계정의 Google Drive에 저장됩니다. 수업로그 개발자가 운영하는 별도의 서버에는 사용자의 학생, 학급, 수업, 평가 및 활동 데이터를 저장하지 않습니다.

4. 데이터 공유

수업로그는 사용자의 데이터를 광고 목적이나 제3자 판매 목적으로 공유하지 않습니다.

5. 접근 권한 해제

사용자는 수업로그에서 Google 연결을 해제하거나 Google 계정의 보안 설정에서 언제든지 수업로그의 접근 권한을 철회할 수 있습니다.

6. 정책 변경

기능 또는 데이터 처리 방식이 변경되는 경우 이 페이지의 개인정보처리방침을 함께 갱신합니다.
